首页 › EssentialsX

EssentialsX

传送 · 家 · 经济 · 基础命令

生存服的「生活工具箱」：设家、传送请求、公共传送点、转账记账、牌子商店。没装它很多基础命令都不存在。

机制与命令

场景命令要点
家/sethome [名] · /home [名] · /delhome · /renamehome多家要权限节点 + 数量节点
传送请求/tpa /tpahere /tpaccept /tpdeny /tpauto /tpacancel默认 120 秒超时，最多 5 条排队
强传 / 返回/tp /tphere /back /spawn可配延迟与冷却
公共点/setwarp /warp /delwarp /warpinfo可按 warp 分权限
经济/balance /pay /eco give|take|set|reset /balancetop可接 Vault 外部经济
商店/worth /sell /setworth；牌子 [Buy]/[Sell]/[Trade]扣款走 Vault

家上限默认：普通 3 / VIP 5 / 管理 10；无限用 essentials.sethome.multiple.unlimited。TPA 默认 120 秒超时、最多 5 条排队；传送可配延迟与冷却；改配置后 /essentials reload。别名前缀 ~；OP 名色可配；经济走内建或 Vault。

怎么用（新手）

  1. 安家
    站好位置输入 /sethome。要第二个家就命名：/sethome 矿洞。
  2. 回家 / 回死亡点
    /home 或 /home 矿洞；死了用 /back。
  3. 找朋友
    /tpa 朋友名，对方输 /tpaccept。拒绝用 /tpdeny。
  4. 设公共传送
    管理员 /setwarp 商城，玩家 /warp 商城。
  5. 用钱
    看余额 /balance；转账 /pay 对方 50；管理发钱 /eco give 玩家 100。

常见坑

  • 多家要同时有 essentials.sethome.multiple 和 ...multiple.等级，少一个仍只能 1 个家。
  • Warp 默认人人能去；要按点限权再开 per-warp-permission。
  • /pay 有最低金额；透支要 essentials.eco.loan。
  • 别的插件也占了同名命令时，看 overridden-commands。

首页 › LuckPerms

LuckPerms

权限与用户组

权限总管：谁能用什么命令、显示什么前缀、属于哪一组。Bungee/Velocity 跨服也可用。

核心概念

概念含义
权限节点字符串，true / false / 未设；* 通配
Group权限打包；用 parent 继承（组套组、人挂组）
Track只做升降级轨道（promote），不负责继承
Meta前缀/后缀/自定义键值

常用命令

任务命令
授权限/lp user|group <名> permission set <节点> true|false（另有 unset / check）
挂组... parent add|remove|set <组>
前缀... meta setprefix 100 "&a[VIP]"
升降级/lp user <人> promote|demote <track>
建轨道/lp createtrack staff → lp track staff append helper
调试/lp verbose record <人> → 让他执行 → paste

怎么用（服主）

  1. 先给自己管理
    控制台：lp user 你的ID permission set luckperms.* true（装好后默认没人有 LP 权限）。
  2. 建组
    lp createtrack staff；lp track staff append helper 再 append mod。
  3. 给 VIP 多家
    lp group vip permission set essentials.sethome.multiple true 以及 ...multiple.vip true。
  4. 加前缀
    lp group vip meta addprefix 100 "&6[VIP]"（数字大者优先显示）。
  5. 加人 / 升级
    lp user 张三 parent add vip；升级 lp user 张三 promote staff。

常见坑

  • Track 只管升降级；真正给权限靠 parent 继承。
  • 时长大小写敏感：1M 是一月，1m 是一分钟。
  • 前缀数字越大越优先；多组冲突看 setweight。
分类：LuckPerms
首页 › CoreProtect

CoreProtect

查证与回滚

方块「监控 + 撤销」：谁挖了什么、箱子里少了啥，可查可回滚。反破坏神器。

命令一览

命令作用
/co inspect（/co i）手查模式：点方块看改动
/co lookup（/co l）只查不改；默认全服范围
/co rollback（/co rb）回滚
/co restore（/co rs）恢复（撤销回滚）
/co undo反着做上一次 rb/rs
/co near等于 r:5
/co purge t:30d清旧日志

时间 t:30s/5m/7h/2d/1w，可组合 5d2h、区间 1h-2h。
过滤 u:玩家 · r:10（回滚默认半径 10）/ r:#global / r:#worldedit · a:+block|-block|container|kill|command|sign · i:物品 · e:生物 · f:文本。
附加 #preview · #count · #summary · 翻页 /co l 2。

怎么用（管理员）

  1. 手查
    /co i 后左键可疑方块，看谁改的。
  2. 查失窃
    /co lookup u:可疑ID t:1d a:-block i:diamond_ore。箱内要用 a:container。
  3. 处理熊孩子
    先 /co rollback u:熊孩子 t:2h r:20 #preview 预览。
  4. 真回滚
    确认后去掉 #preview。回多了 /co undo 或 /co restore。
  5. 清理
    定期 /co purge t:30d，防日志占满磁盘。

常见坑

  • lookup 默认全服；rollback 默认身边 10 格。不写 r: 易查爆或回错范围。
  • 务必先 #preview；r:#global 要极谨慎。
  • 时间必须带单位（t:1 不合法）。
  • 箱内物品用 a:container，不能只查 a:block。

首页 › 商店

商店

QuickShop-Hikari 箱子店 · ChestShop 牌子店

两套商店：QuickShop 对箱子开店；ChestShop 用告示牌开店。同装会抢事件，建议只用一套。

QuickShop-Hikari 箱子商店

店型：① 出售店（店→玩家）② 收购店（玩家→店）③ 双向店（双箱或买卖并存）。支持 NBT/附魔/药水精确匹配、无限店、店名/描述、展示物。

命令作用
/qs create <价格>注视箱子建店；手持商品确认
/qs buy / /qs setprice设为收购 / 改价
/qs price · /qs info · /qs remove改价 · 看库存 · 拆店
/qs setowner · /qs staff转让店主 · 店员
/qs name · /qs desc · /qs silent · /qs find · /qs about店名 · 简介 · 静音 · 查找 · 信息
/qs unlimited · /qs taxaccount · /qs range无限货 · 税户 · 范围（管理）
/qs clear · /qs purge · /qs reload · /qs backup清空 · 清理 · 重载 · 备份（管理）

交易：左键买、右键卖（可配置）；交互冷却默认约 0.1s 防刷。库存不足拒售；收购需你背包有货。

费用：建店费、交易税、最低/最高价、价格单位在 config；税进 tax-account。每玩家店数/每店交易量有上限。

权限：quickshop.quickshop · create · buy · sell · others · admin · bypass · free · notax。

存储 H2/MySQL；可接 WorldGuard/GriefPrevention/Dominion；改 jar 后勿用 /qs reload 热替换，易崩。

ChestShop 牌子商店

牌四行写法：（贴在箱子上/旁）

行内容示例
1店主名，或 Admin ShopSteve / Admin Shop
2数量（可写 B/S 表示买/卖）1 或 B 1
3单价；B 5 买 · S 5 卖 · B 5:5 S 双向B 5:5 S
4物品名/ID（/iteminfo 查询）DIAMOND

店型：Buy（玩家买）· Sell（玩家卖）· Admin Shop（无限，需管理权限）。双向用 B x:y S。

命令作用
/iteminfo查物品 ID
/shopinfo（/shop）看指向的店
/csaccess切换「可开箱却不能交易」
/csgive · /csmetrics · /csversion代建店 · 统计 · 版本（管理）

权限要点：ChestShop.shop.create|buy|sell · create.buy|create.sell · shop.buy.(id) · shop.sell.(id) · admin|mod · nofee 免建店费 · notax.buy/notax.sell 免税。

费用与限制：建店费 + 成交税；交互冷却防刷；默认有开箱权也不能交易（防掏空店主）；创造模式默认禁止交易；NBT 不匹配报无货。经济走 Vault。

分类：商店
首页 › BlueMap

BlueMap

3D 网页地图

浏览器里看服务器 3D 地图：找朋友建筑、看地形、搜标记。

怎么用

  1. 玩家打开网页
    浏览器访问 http://服务器IP:8100（默认端口 8100）。
  2. 浏览
    拖动、缩放、点标记；建筑内部可切洞穴/楼层视图。
  3. 管理重载
    /bluemap reload 改完配置后执行。
  4. 全量重渲
    大改地图后 /bluemap fullrender <map>（很吃 CPU/磁盘，避开高峰，别中途强关）。
  5. 对外访问
    防火墙/反向代理放行 web 端口；可配多世界、分辨率、POI。

常见坑

  • 8100 未放行或被占用 → 外网打不开。
  • 只渲染已生成区块；没探索过的地方是空的，不是坏了。
  • 关「实时玩家」标记可保护行踪。
分类：地图
首页 › AuthMe

AuthMe

登录 · 注册 · 防盗号

进服先验证身份。未登录时不能聊天、不能动、强制生存；注册登录后才恢复完整权限。支持邮箱找回与二步验证。

命令

场景命令
注册/register 密码 确认密码（/reg）
登录/login 密码（/l /log）
改密/changepassword 旧 新（/cp）
注销 / 退出/unregister 密码 · /logout
邮箱找回/email show|add|change|recover|code|setpassword|confirm
二步验证/totp code|add|confirm|remove（/2fa）
管理/authme register|unregister|forcelogin|password 等

怎么用（新手）

  1. 首次进服
    /register 你的密码 再输一遍，两次必须一致。
  2. 以后每次
    /login 密码 后才能玩。
  3. 绑邮箱
    /email add 邮箱 后 /email confirm；丢号用 /email recover。
  4. 改密
    /cp 旧密码 新密码。
  5. 可选 2FA
    /totp add 绑定验证器。

常见坑

  • 密码两次不一致会拒注；特殊字符看服规。
  • 默认禁止多开小号；AntiBot 可临时拦新号。
  • 忘密优先邮箱找回，再找管理重置。

ExcellentEnchants（75+）

ExcellentEnchants 共 75+ 条原版风附魔，品质普通/勇者/史诗/神话，可从附魔台、村民、战利品、钓鱼、怪装获得；管理命令 /book /randombook /disenchant /givefuel。具体词条以游戏内 GUI 列表为准。 管理发书：/book 玩家 附魔 等级；随机书 /randombook；拆解 /disenchant。

怎么获得附魔书

  1. 附魔台 / 铁砧 / 村民 / 钓鱼 / 怪装：杰出附魔会塞进这些途径。
  2. GUI 附魔台：/enchanter，按品质花经验抽取（普通 40% → 神级 1%）。
  3. 管理发放：/book 精确指定附魔与等级。

SimpleVoiceChat

游戏内语音

附近玩家语音，可开群组开黑。客户端必须装同版本 mod 才能听/说。

项说明

群组与附近语音是两套音量/范围
说话默认按键说话（客户端绑 PTT）

怎么用

  1. 安装客户端 Simple Voice Chat mod。

TAB · ScoreboardPL

Tab 列表与侧边栏

TAB 管按 Tab 的玩家列表、头顶名、Ping；ScoreboardPL 管右侧侧边栏。本服 TAB 里侧栏关着，避免叠两层。

玩家会看到什么

  • Tab 顶/底横幅 + 玩家列表 + Ping；头顶名字按权限组排序。
  • 侧栏：名、等级、血量、食物、钱、坐标、时间、在线/TPS 等。
  • /scoreboard toggle（别名 sb）开关侧栏。

管理怎么配

  1. TAB
    改 header-footer 文案；sorting-types 的组名要与 LuckPerms 组一致。
  2. ScoreboardPL
    改 title、lines（最多 15 行）；支持 %vault_*、%luckperms_* 等占位符。
  3. 时区
    建议改成 Asia/Shanghai。
  4. 重载
    /tab reload · /scoreboard reload。

常见坑

  • 没装 Vault/LuckPerms 时占位符显示成原字面量。
  • 侧栏超过 15 行会截断；两插件都开侧栏会重叠。

Veinminer 连锁挖矿

挖一块 · 整条矿脉碎

挖矿脉里任意一块，相连同类方块一起碎。另有附魔附属「连锁采矿」。

怎么挖

  1. 对矿脉正常挖掘其中一块（默认原版矿）。
  2. 条件满足时整条一起碎、一起掉。
  3. 本服必须蹲下（潜行）才会连锁挖矿（mustSneak）。
  4. 工具要挖得动（默认 needCorrectTool：镐挖矿、斧砍原木）。

命令与默认限制

命令作用
/veinminer blocks add|remove改可连锁方块表
/veinminer groups按组限制方块+工具
/veinminer settings全局开关与数值
/veinminer toggle全服开/关
  • maxChain 默认约 100 块/次；冷却约 20 刻。
  • 耐久按块扣；可配每块饥饿。
  • 附魔版开着时，没有「连锁采矿」附魔的工具不会连锁。

常见坑

  • 大矿脉一次掉太多会卡，调低 maxChain。
  • 工具挖不动的方块连锁也不掉（除非关 needCorrectTool）。

管理与杂项插件

备份 · 榜单 · 菜单 · 防泄露 · 小工具

AdvancedBackups 备份

自动备份世界的保险柜，可定时/手动打包，坏档可按快照恢复。

  1. 放入 plugins/ 后开服生成配置。
  2. 立刻备一份：/backup start。
  3. 出事 /backup snapshot 看点，再按说明恢复。
  4. 改配置 /backup reload-config；链乱了 /backup reset-chain。

权限 advancedbackups.backup；备份目录别和世界挤爆同一块盘。

AsLeaderBoard 排行榜

钱/击杀/死亡/时长 Top 榜，聊天或箱子 GUI 展示。

  1. 需要 Vault（钱）+ PlaceholderAPI。
  2. 玩家 /leaderboard（/lb）、/baltop。
  3. GUI 条目改 gui-items.yml，聊天格式改 chat-formats.yml。
  4. /leaderboard reload 重载。

没经济插件时金钱榜会一直空；默认命令冷却约 3 秒。

DailyRewards 每日奖励

每日抽一次礼包（物品 + 控制台命令）。

  1. 玩家 /daily 领取；可配置上线自动领。
  2. 午夜本地重置；管理 /daily give / reset / reload。
  3. 奖励池在 config.yml 的 rewards 权重里改。

不依赖 Vault；用 eco give 发钱时要保证经济插件在。

DeluxeMenus 菜单

YAML 拼箱子菜单：主城导航、商店入口、每日签到等。

  1. 菜单文件放 gui_menus/。
  2. 打开：/dm open <菜单>。
  3. 权限 deluxemenus.menu.<id> 或 deluxemenus.open。
  4. 改完用 /dm reload。

占位符依赖 PlaceholderAPI 等 softdepend；缺前置时菜单可能空白。

SeedGuard + SeedShield 防看种子

防止玩家用世界种子算遗迹/拆家。Guard 堵 /seed 等；Shield 给结构盐加密，爆破工具对不上。

  1. 两个都装；Shield 建议 load: STARTUP 尽早加载。
  2. Guard：设 fake-seed.mode（推荐 per_player_stable）并立刻改 salt。
  3. Shield：配置 secret-key 与 enabled-worlds。
  4. 管理绕过：seedguard.bypass。

删掉/更换 secret-key 会重排全部结构，等于换了一张新世界地形分布，务必备份密钥。

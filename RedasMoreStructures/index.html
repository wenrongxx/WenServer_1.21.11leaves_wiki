    首页 › 配置

    配置指南

    Config

    路径：data/redsmorestructures/worldgen/structure_set/

    参数含义示例
    spacing生成尝试间距（区块），越大越稀有32
    separation两结构最小间距（区块）26
    chunk_count排除区大小（区块）5
    weight结构集内相对概率1

    推荐频率

    频率spacingseparation
    非常常见1612
    常见2418
    默认3226
    稀有4836
    非常稀有6448

    禁用结构

    1. 从 structure_set JSON 的 structures 数组移除条目
    2. 直接删除 structure_set/NAME.json
    3. 在 worldgen/structure/NAME.json 中改 biomes 为无效群系（如 minecraft:the_end）
    worldgen 仅在新建世界时读取；改 JSON 前请备份并校验合法性。config.txt 文档与磁盘 JSON 可能不完全一致（文档写合并集，实际多为单结构文件），以文件为准。

    RPG Skill Plugin
    mcMMO
    名称mcMMO

    mcMMO 把挖矿、伐木、战斗、钓鱼等核心玩法做成可升级的 RPG 技能：练级解锁子技能，部分技能可触发超能力，并支持队伍经验分享与传送。

    • 默认 Retro 模式（0–1000）；可在 config 切换 Standard（0–100）
    • 力量等级 = 非子技能等级之和；单技能上限默认 0（不限制）
    • 数据：FlatFile 或 MySQL（表前缀 mcmmo_）；区块数据在世界目录 mcmmo_regions
    • 公共 API：ExperienceAPI · PartyAPI · AbilityAPI · SkillAPI · ChatAPI · DatabaseAPI
    • 服务器可在 General.Locale: zh_CN 启用简中；运行时 /mcmmoreloadlocale 热重载语言

    等级与模式

    Retro vs Standard · XP 公式
    项目Retro 模式（默认 true）Standard 模式
    技能范围多数 0–1000（部分后期技能可达 10000）多数 0–100（部分可到 1000）
    升级手感频繁小升级较少大升级
    满级耗时相同（数值 ×10 同步）相同
    技能分类采集 / 战斗 / 杂项；分解与冶炼为子技能（无独立等级，XP 由父技能均分）同左

    XP 公式（experience.yml + FormulaManager）

    模式公式默认参数满级示例
    LINEAR（默认）base + level × multiplierbase=1020, multiplier=20Retro 从 0→1000 线性累积
    EXPONENTIALmultiplier × level^exponent + base0.1×level^1.80 + 2000后期更陡
    Standard 换算标准级 N ≈ Retro 区间 (N×10+1)…(N×10+10) 之和——
    • 力量等级 Power Level = 全部非子技能等级之和（分解/冶炼不计入）
    • 全局倍率：Experience_Formula.Multiplier.Global（默认 1.0）；PVP 倍率独立
    • 默认开启前期加速、战斗 XP 上限（单次伤害 100）；刷怪笼/刷蛋生物 XP 默认 0
    • 收益递减 Diminished_Returns 默认关闭；开启后阈值约 20000 XP/10 分钟，最低保留 5%
    • 升级里程碑广播默认每 100 级

    XP 计算公式

    FormulaManager · 倍率链 · 累计经验

    升级所需经验

    曲线公式默认
    LINEAR（默认）need = base + level × multiplier1020 + 20×level；下限 1
    EXPONENTIALneed = multiplier × level^exponent + base0.1×level^1.80 + 2000

    累计约：Retro 100 级 ≈ 20.1 万 XP，1000 级 ≈ 1101 万 XP。Retro/Standard 切换不改变总肝度。

    倍率链

    最终XP = 原始XP × Skill_Multiplier × max(Global, /xprate) × CustomXPPerk(默认1.25)
    • /xprate 与 Global 取 max，不叠加
    • 等级或力量等级到 Cap → 不再给经验
    • Cumulative_Curve 建议保持 false；曲线建议 LINEAR

    战斗经验机制

    AwardCombatXpTask · CombatUtils
    单次命中XP = min(本次实际打掉的血量, 100)
          × 怪物倍率 × 10 × 通用倍率链

    三条硬规则：

    • 按实际扣血算，不是武器面板伤害；超杀不给 XP
    • 单次伤害 XP 上限按 100 计（Damage_Limit）
    • 每次攻击事件结算一次；剑术利刃突刺等 AoE 不给 XP

    伤害类型：什么不算 XP

    • 摔落、岩浆、窒息、溺水、营火、仙人掌
    • 铁傀儡 / 雪傀儡 / 狼 / 其它生物造成的伤害与击杀

    • 玩家自己放置/活塞推移的方块：采集类无经验

    农场设计与加速开关

    怎么刷才有效率

    战斗农场原则

    • 必须自然生成（NATURAL），不要用刷怪笼方块
    • 怪要满血由玩家亲手击杀；禁止摔落/岩浆/宠物预处理
    • 落差 ≤3 格（摔伤 = 落差 − 3）
    • 高血量怪分多刀，每刀 ≤100 伤以吃满上限；一击秒 20 血小怪最省事
    • 注意世界黑名单与其它插件 NPC 判定
    农场思路目标约 XP/只备注
    下界要塞自然刷新 + 玫瑰过滤 + 过门后手动处死凋灵骷髅 4.0×20800玫瑰只滤凋灵骷髅；过门不重置 SpawnReason（建议实测）
    主世界黑暗刷怪塔（自然）苦力怕 800 / 骷髅 600 / 僵尸 400按倍率禁止摔落残血
    幻翼（不睡觉）幻翼 4.0×20800—
    Warden6.0×500约 3 万多刀、风险高
    采集天然矿脉/树木/作物按方块表不要自己放置后再挖
    炼药完整酿造链三瓶约 1.7 万材料成本高，可漏斗挂机（默认允许）

    加速开关（调平衡）

    优先级开关效果
    ★★★关掉 XPCeiling高血量怪一击吃满（对格斗几乎无效）
    ★★★满血亲手击杀相对残血可差数十倍
    ★★☆Multiplier.Global / Skill_Multiplier全技能或单技能加倍
    ★★☆/xprate运行期倍率，与 Global 取 max
    ★☆☆customboost 权限+25%
    ★☆☆Mobspawners.Multiplier 1.0允许刷怪笼农场
    ★☆☆关 EndermanEndermiteFarms解封末影人塔
    保持关Diminished_Returns、Cumulative_Curve显著拖慢
    保持Curve=LINEAR指数曲线更难

    核心玩法循环

    How mcMMO plays

    mcMMO 不改原版生存主循环，而是在其上叠加技能等级、被动触发、主动超能力、队伍协作与成长目标。

    环节玩家做什么mcMMO 反馈
    采集挖矿、砍树、锄地、钓鱼、铲土对应技能 XP；双倍/三倍掉落；母矿、繁茂恩赐等被动
    战斗剑/斧/弓/弩/空手/驯兽等技巧射击、暴击、撕裂、缴械等子技能；极限突破 PVP
    主动技能手持工具右键就绪超能力：三倍挖矿、整树砍倒、狂暴、斩首者等
    成长升级、解锁子技能子技能 Rank；超能力解锁（如 5/50 级）
    社交组队打怪/刷本队伍经验加成、共享、传送、物品分配
    目标冲榜、精通、Hardcore/mctop 排行；力量等级；死亡扣级或击杀吸级
    • 技能详情命令如 /mining /swords 可随时查看 XP 与子技能
    • 被动几乎不打断操作；主动超能力有冷却，需规划战斗/采集节奏
    • 服务器常用 PlaceholderAPI 排行榜、记分板（默认关）展示成长

    队伍系统

    Party · XP 分享

    组队共享经验、聊天、传送与物品分配。Party.Enabled 默认 true；人数上限默认 MaxSize: -1（无限）。

    队伍经验分享公式

    shareBonus = min(1.1 + 队伍人数 × 1.05, 1.5)
每人获得 XP = 总 XP ÷ 人数 × shareBonus
（仅 EQUAL 模式；分享半径默认 75 格）

    队伍等级解锁（config.yml）

    队伍等级解锁功能
    1队伍聊天
    2队伍传送 /ptp
    5队伍同盟 Alliance
    8物品共享 ItemShare
    10经验共享 XpShare（上限 Level_Cap=10）

    传送配置

    • /ptp 冷却 120s，预热 5s，受伤后冷却 60s，请求超时 300s
    • 需对方接受（Accept_Required）；管理员可 /mcchatspy 监视队伍聊天

    首页 › 配置要点

    配置要点

    config.yml / skillranks.yml
    • General.RetroMode.Enabled：Retro / Standard 模式
    • General.Locale：语言（服务器可改为 zh_CN）
    • General.Level_Up_Chat_Broadcasts：升级广播与里程碑间隔
    • General.Save_Interval：玩家数据保存间隔（分钟，默认 10）
    • General.Power_Level_Cap：力量等级上限（0 表示不限制）
    • General.Refresh_Chunks：超级碎石机等结束后刷新区块（性能换正确性）
    • coreskills.yml：按技能开关子技能（如 Acrobatics.Roll.Enabled）
    • skillranks.yml：子技能解锁等级（Standard 与 RetroMode 分列）
    • config.yml 在启动时加载一次，运行时不支持 /reload（可用 mcmmoreloadlocale 重载语言）

    skillranks 示例（Standard / Retro）

    子技能标准模式解锁Retro 模式
    炼金·混合 Rank1–80 / 10 / 20 / 35 / 50 / 75 / 90 / 1000 / 100 / … / 1000
    箭术·极限突破 Rank1–1010→100（每阶 +10）100→1000
    箭术·技巧射击自 1 级起多阶解锁×10

    服务器管理员可在 skillranks.yml 将全部 Rank 调为 0，使子技能开局即全部可用。

    与服务器其它 Wiki 的关系：数据包（墓石地牢、DnT、Incendium 等）提供内容与掉落；mcMMO 提供角色成长与防刷平衡。二者组合即 WenServer 的玩法骨架。

    WenServer 汉化材质包

    Merged resource pack for server datapacks
    WenServer 材质包
    描述一款适用于WenServer的材质包，合并了多个数据包的材质包
    类型资源包（材质 + 语言 + OptiFine CIT）
    pack_format75 · supported 15–500
    lang 命名空间dnt · incendium · minecraft · terralith · structory · structory_towers · nullscape
    中文键合计约 1800+
    未覆盖RedasMoreStructures · DeadlyDeadlyDungeon · gravestone（无对应 lang）

    WenServer 汉化材质包将各数据包的 lang 与材质合并，使客户端在服务器上看到统一的中文结构名、物品名与进度标题，并为 Incendium / DnT 等提供物品模型。

    overlay 目录内无独立 pack.mcmeta，元信息集中在主 pack 的 overlays.entries。

    服务器使用说明

    How to use
    1. 客户端安装 WenServer.zip（或由服务器资源包链接自动下发）。
    2. 服务器同时安装对应数据包（DnT、Incendium 等）。
    3. 进入游戏后，结构名、物品名、进度标题应显示为中文。
    4. 若某结构仍为英文：检查该包是否自带 lang，或 lang 键是否本就未译（如 Incendium 的 structure.incendium.*）。
    5. Redas / Deadly 等包无 lang，需依赖 Wiki 译名或后续自定义语言文件。

    缺口说明

    • WenServer 中没有 redsmorestructures / ddd / gravestone 命名空间 lang
    • Incendium 结构键未译，可参考本工作区 Incendium Wiki 的中文推导名
    • DnT 结构名以 5.1.0 zh_cn 为权威
    本工作区各数据包 Wiki 中的中文名优先采用 WenServer / 数据包自带 zh_cn。

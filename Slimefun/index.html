一、粘液科技是什么

粘液科技（Slimefun）将 Minecraft 扩展为无需模组的科技树：材料加工、机器、电力、货运、机器人、魔法与大量附属。所有粘液物品带专用标识，需在强化工作台等粘液机器中按指南书配方制作，不能用原版合成台「拼样子」完成。

二、本百科怎么读

  • 核心系统：研究 → 材料 → 机器 → 电力 → 物流 的理解顺序
  • 官方附属：幸运方块、矿石块、灵魂罐、木龙头、刷怪笼、异域花园、环保能源、背包与捕捉等
  • 社区附属：Networks、DankTech2、简易存储、匠魂、美食家、无尽、动力、EMC…
  • 附录：玩法指南、命令、本服配置

怎么玩：果园从剪草到结果

在草地里剪出树苗/灌木苗，种成水果树和菜。这是最轻松的入门支线，不用机器也能玩。

开始前你要有：剪刀（或空手）、泥土。不需要研究和电力。

  1. 准备一小块地
    找平坦草地挖 2～3 条垄，方便来回采摘。前期不用围栏。
  2. 去剪草拿苗
    对着草方块、短草、高草、蕨挥剪刀或手。破坏后有概率掉树苗或灌木苗（本服树约 22%、灌木约 16%）。高草和大型蕨更值得多打，普通短草掉率低。
  3. 认识苗的名字
    「樱桃树苗」「椰子树苗」会长成树；「葡萄灌木」「番茄灌木」直接结果。名字里带吃的都有用。
  4. 种下
    和原版树苗一样种在土上。树与树隔 2～3 格，太密会挤。灌木可稍密。
  5. 等待长大
    树苗要长一段时间；灌木更快。树苗期别用斧砍。
  6. 采摘
    树上的果实方块打掉/摘下进背包；灌木上的果实同理。这就是你的第一批产品。
  7. 扩大与出售
    做第二块田；水果可以卖给美食家玩家，或自己做菜（见美食家）。想要稀有苗就回去剪高草。
  8. 后期自动化
    产量大了以后，用漏斗/货运接掉落，变成无人值守果园。

新手问题：「剪了半天不掉？」→ 去打高草/大型蕨。下界和末地不会长这些植物，别拿去地狱种。

怎么玩：开一间电刷房

通电就刷怪的笼子。配合灵魂罐，变成「自动出怪 + 收灵魂」工厂。

开始前你要有：破损刷怪笼（灵魂罐做）、煤发电机+电缆、封闭小房间。

  1. 搭杀怪室
    用石头围一个 3×3 左右小房间，留 1 格小口方便你砍怪，其余全封死。
  2. 放笼并选怪
    电力刷怪笼放在房间里，右键界面选本服允许的生物（约 25 种）。
  3. 拉电
    约 240 J 才刷一只，缓冲 2048 J。电缆接发电机，建议加电容，否则一停一刷。
  4. 漏斗收掉落
    地板下漏斗 → 箱子。肉、骨头、装备自动进箱。
  5. 开刷与击杀
    怪会持续出现。你在小口砍；记住 4 格内同种怪上限约 6，多了要及时杀。
  6. 同时灌灵魂
    背包放灵魂罐，你杀的同计灵魂。两条线一起涨。
  7. 以后再自动化
    用自动杀怪装置+货运，变成无人车间。

注意实体数量与卡顿；掉落箱满了要清，否则漏斗会堵。

怎么玩：从一堆箱子到联网仓库

控制器联网后，所有仓变成一个「大超市」：统一搜、统一拿，还能自动合成。类似 AE2/应用能源。

开始前你要有：较多铁/金/电子料；强化工作台；家里已有一堆乱箱子。

  1. 做控制器
    网络主脑，放在仓库中间。一个网络只能有一个控制器。
  2. 用桥铺范围
    控制器覆盖不够时，用桥把网络往外接。
  3. 挂单元当箱子
    「单元」像双箱（54 格）。不够用就做「量子存储」（4096 个起，一直到几乎无限）。
  4. 放网格
    网格=检索窗口：打字搜物品、存取。日常你只开这个界面。
  5. 学会导入/导出
    Import 从普通箱子吸进网；Export 往机器吐。以后矿线、农场全靠它。
  6. 自动合成（进阶）
    配方编码器记住配方 → 自动合成机 64 J/次自动做（Withholding 128 J 可扣留一组）。
  7. 远程器
    四档：150 / 500 / 同维不限 / 跨维。要先在网格绑定，且区块加载。
  8. 清理垃圾
    Purger 设过滤把垃圾清零；量子仓可开「丢弃溢出」防堵。
  9. 取存习惯
    取出：单元 → 扣留合成器 → 贪婪 → 桶。放入：贪婪 → 桶 → 单元。

别放两个控制器试图合网（会被取消放置）。工业存储单元可用监视器接入。

    包 1 只有 1 槽但能装 256 个同种物品。档位升高：槽更多、单槽上限更大（包 9 接近无限）。

玩法指南

操作步骤 · 与机制百科对照

这一章假设你完全没玩过粘液科技。先弄懂三个词：
① 研究：用经验等级买下配方，不研究做不出来。
② 强化工作台：粘液专用合成台，不是原版工作台。
③ J（能量）：机器的电，由发电机供给。

第一天：从零到第一把粘液镐

  1. 进服先看背包
    首次进入会自动送你一本《粘液科技指南》。没有就输入 /sf guide。这本指南就是你的配方书，后面所有物品怎么做都看它。
  2. 右键打开指南
    左边是分类（基础、工具、机器、电力、货运…）。先只看「基础」。里面会写着某物品需要什么材料、在哪个台子做、有没有「研究锁」。
  3. 认识「强化工作台」
    指南里搜「强化工作台」。它通常要铁砧和一些铁/木板（以你游戏内指南为准）。这些材料用原版工作台做——因为强化工作台本身还不是粘液物品。做好后放在地上。
  4. 右键强化工作台
    打开的界面仍是 3×3 格子，但只认指南里的配方。你把材料按格子摆对，右边出成品。原版合成台做不出粘液装备，这是新手最容易卡住的点。
  5. 解第一个研究
    指南里找一把基础镐/斧。若物品上有锁或写「已锁定」，点研究按钮。它会扣你的经验等级（不是钱）。
    · 成功：提示「成功解锁研究」。
    · 失败（本服约 1%）：提示「研究失败! 你需要再试一次」——再点即可，等级还在。
    · 等级不够：去挖几组煤、杀几只怪，或跑一趟地牢再来。
  6. 做出第一把粘液工具
    研究完成后，回强化工作台，按指南格子放材料，取出工具。这时你已经打通「看指南 → 解研究 → 工作台合成」整条链。

第一周：把石头变成电路板（材料线）

粘液的逻辑是：把矿变多，再把多出来的粉变成更高级材料。你以后几乎每个机器都要电路板，所以这条线优先。

  1. 做「粉碎机」类机器
    指南搜「粉碎机」或「矿研磨机」。先做最便宜的那台。它需要你刚才解过的研究和一些金属。
  2. 喂原矿
    打开机器界面，把铁矿/金矿/铜矿放进去。它会慢慢1 矿 → 2 粉（这是粘液倍增矿产的核心）。
  3. 洗矿 / 淘金（可选但推荐）
    「淘金盘」对着沙砾使用，有概率筛出铁粒、金粒、黏土等。「洗矿机」把粉再洗一遍，副产石粉。这一步是「变废为宝」。
  4. 熔成锭
    电炉或冶炼炉把粉 → 锭。2 粉 = 2 锭，所以「粉碎再熔」等于原版挖矿的两倍。
  5. 做合金与电路板
    指南搜「粘液合金」「基础电路板」。配方在强化工作台。高级电路板是后续机器的门票——看到缺它就回这条线补材料。

第二周：让机器自己转（电力 + 货运）

  1. 先做煤发电机
    指南搜「煤发电机」。放好后往里塞煤，它开始产J（能量）。
  2. 拉「粘液电缆」
    电缆把发电机和机器连起来。中间可加「电容」存电（像电池）。
  3. 用万用表检查
    手持万用表对机器/电容右键，会显示「已储存的能源: 当前 / 上限」。机器不转时先看这里是不是 0。
  4. 做货运节点
    「输入」节点贴在「有货的箱子」上，「输出」节点贴在「要收货的箱子/机器」上。再放一台「货运管理器」通电。
  5. 设定同一频道
    右键管理器，建一个频道（比如叫「矿线」）。把输入、输出节点都设成这个频道。丢 1 个矿进输入箱，几秒后看会不会到出口箱。通了再量产。
  6. 接自动合成机（进阶）
    把自动合成机放在箱子正上方。手持你想要的成品，蹲下 + 右键机器写入配方。原料箱塞够料就自动做。

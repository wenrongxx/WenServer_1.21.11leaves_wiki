    试炼钥匙

    Trial keys

    试炼刷怪笼（trial_spawner）掉落定制 trial_key / ominous_trial_key（改名 + CMD 模型），用对应保险库开启 Boss 奖励。

    CMD 标识中文物名来源用途
    golden_key黄金钥匙普通 BillyBilly 的保险库
    scorching_key灼热钥匙普通 BobBob 的保险库
    rotten_key腐坏钥匙普通 Pig下界风格保险库
    spider_key蜘蛛钥匙普通 Spider蜘蛛 Boss
    knight_key骑士钥匙普通 Tomb坟墓 / 骑士
    tower_key高塔钥匙普通塔 Boss塔顶宝箱
    wizard_key巫师钥匙普通巫师 Boss巫师塔

    每个 Boss 另有 不详（ominous）钥匙变体，战利品更强。

    机制摘要

    Gameplay
    1. 试炼钥匙 → 保险库：normal / ominous 双轨难度
    2. 分层地牢 liv1–4：敌人装备从皮革升级到钻石
    3. 函数仅：创建 tower 队伍、关闭指令输出、结构清理；Boss AI 多在 NBT 命令方块内
    4. 加载钩子：ddd:tower_team + ddd:command_hide
    5. 兼容 Terralith / BoP / Biomes We've Gone / Terrestria 群系标签（required:false）
    6. 许可：私有 Limited Rights — 允许个人非商业与含署名整合包/服务器；禁止单独再分发、修改逆向、商业用途
